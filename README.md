# ML Portfolio
Мои учебные проекты по классическому машинному обучению.

## Структура репозитория
- `01_Lin_reg` — Линейная регрессия
- `02_Log_reg` — Логистическая регрессия
- `03_кросс_валидация` — Кросс-валидация
- `04_KNN` — Метод ближайших соседей
- `05_Decision_Tree` — Деревья решений
- `06_Random_Forest` — Случайный лес
- `07_Adaboost` — Адаптивный бустинг

## Ключевые проекты
- **German_Credit_Data.ipynb** — анализ кредитного скоринга.
- **Breast_Cancer_Wisconsin.ipynb** — классификация опухолей.

## Стек
Python, Pandas, Matplotlib, Seaborn, Scikit-learn, Git, Catboost, Postgresql, Jupyter Notebook.
